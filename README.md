# K-Nearest Neighbors Classification - 

## Project Description

This project implements the K-Nearest Neighbors (KNN) algorithm manually using Python.

The algorithm is implemented without using any Machine Learning library.

The project demonstrates how a new data point can be classified using Euclidean distance, nearest neighbors, and majority voting.

## KNN Algorithm

The program follows these steps:

1. Accept a new data point from the user.
2. Calculate Euclidean distance from all dataset points.
3. Sort the calculated distances.
4. Select the K nearest neighbors.
5. Predict the class using majority voting.
